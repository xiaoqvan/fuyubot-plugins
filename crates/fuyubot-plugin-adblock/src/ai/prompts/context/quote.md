# QuoteMessage 规则

quoteMessage 是其他人的消息，必须与 message 完全分开：message 只能产生 message.keywords，quoteMessage 只能产生 quoted_message.keywords。严禁把 quoteMessage 的关键词放入 message.keywords。

---

## quoted_message.has_ad

只根据 quoteMessage 判断。如果 quoteMessage 是广告：quoted_message.has_ad = true，并且 ad_detected = true（当前用户正在传播/引用广告内容）。但注意：当前用户自己没写广告，不代表 message.keywords 可以包含 quoteMessage 的关键词。

---

## 炸裂文本 ≠ 新闻 → 引流广告

引用内容若文本**特别炸裂**（夸张煽动、猎奇标题党、情绪轰炸式表达，明显超出正常交流/讨论的尺度），而它**不属于新闻或快报类型**（有正规新闻体例、时间地点人物、媒体来源、报道口吻），那么这类文本一般是**引流文本广告**：

quoted_message.has_ad = true
ad_detected = true
confidence 按炸裂与引流程度 0.75~0.95

### 判别要点

* 新闻/快报类型（即使内容劲爆）：正规报道口吻、有事件要素/来源 → 不因此判广告（r18 按内容另判）
* 非新闻体的炸裂文本：纯情绪煽动 + 悬念钩子 + 诱导点击/关注/私信/进群 → 引流广告
* 炸裂程度越高、引流意图越明显，confidence 越高

### 例子（引用消息）

| quoteMessage | 判定 |
| --- | --- |
| “惊爆！这种事居然发生了，不转不是中国人” | 引流广告（炸裂标题党+传播诱导） |
| “看完整个人都不好了，群里说” | 引流广告（猎奇钩子+导流入口） |
| “某地今晨发生地震，已致12人受伤（据新华社）” | 新闻，不是广告 |
| “今日快讯：央行宣布下调存款利率” | 快报，不是广告 |
| “今天天气不错” | 不是广告 |

## 夸大效果的成人文本引诱点击 → 也是广告

引用内容若用**夸大、猎奇、性暗示**话术诱使人点击/关注/私信/进群，即使没有价格、外链、@用户，也应判：

quoted_message.has_ad = true
ad_detected = true
r18 = true
confidence 按强度 0.75~0.95

### 典型特征（单独或组合出现）

* 夸大生理/性效果：变大、变硬、延时、壮阳、增大增粗、猛男、一整晚、受不了、顶不住
* 猎奇悬念：点开看、看完受不了、慎入、别外传、私密片、内部片
* 成人内容暗示 + 点击诱饵：美女视频、福利视频、深夜福利、开车上车、老司机、点击观看、马上看
* 身份暗示引流：空降、楼凤、上门、全套、约、陪玩（引向联系/观看）

### 例子（引用消息）

| quoteMessage | 判定 |
| --- | --- |
| “看完这个，女朋友说受不了” | 广告（夸大效果+成人性暗示） |
| “男人坚持不了一定点开” | 广告（夸大效果+点击诱饵） |
| “深夜福利，点开有惊喜” | 广告 |
| “这个视频太顶了，自己看” | 视上下文；带明显性暗示/引流则广告 |
| 正常技术/新闻讨论 | 不是广告 |

### 与「正常成人讨论」区分

* 新闻/评论/知识讨论成人话题 → 可 r18=true，但 has_ad=false
* 用夸大效果、性暗示**诱使点击/传播** → has_ad=true

---

## 字段隔离

上述判定只写入 quoted_message.has_ad 与 quoted_message.keywords，不要把引用里的关键词复制进 message.keywords。
