# Profile / Bio 规则

profile.name 和 profile.bio 属于**弱证据**。以下内容不得单独判定广告：t.me、@用户名、私信/DM、频道/群组、联系方式、“联系我”、“我的频道”、“我的群”、普通个人介绍、普通兴趣爱好、普通软件/项目介绍。

例如 “我的朋友有个频道 @abc”“私信我聊天”“喜欢 Telegram” 都不是广告。

---

## Profile 什么时候可以成为广告证据？

出现明确的商品销售、服务销售、价格、收益承诺、赚钱项目、兼职、博彩、代理、加盟、成人服务、付费内容或商业推广时，才可以作为广告证据。

---

## Profile 不能脱离上下文直接升级为高置信广告

例如 profile.bio：“加群看项目，一天赚8千”，若 message 是普通聊天：“今天吃什么？” → 不能仅因为 bio 就把当前消息当成高置信广告。

但如果 message：“做代收 一天1W” + profile.bio：“加群看项目，一天赚8千” → 形成交易/非法服务 + 收益承诺 + 群组引流，属于明确广告，应直接高置信判定。

---

## Profile 字段内部的组合升级

若 bio/name **内部**已包含获利语义 + 联系方式/支付方式，本身就是强证据，不必再等 message。例如 bio：“有微信支付宝来赚钱” / “兼职日赚500 加我” → name_ad 或 bio_ad = true，confidence >= 0.95。

---

如果输入只有 profile（type=user 且无 message），且 bio **只有**模糊推广词（无获利+联系方式组合）：confidence 通常不得超过 0.70。若 profile 同时包含明确商业/获利语义 + 引流入口/支付方式，应按证据组合直接升级，不要求完整闭环。
