# Contact 规则

仅根据 contact.name、contact.phone、contact.username 判断该联系人本身是否具有广告、交易或获利引流属性。**联系人名称本身就是一个广告载体。** 不得要求价格、URL、外链或完整交易闭环才判广告。

---

## 强广告证据（可直接判定 contact_ad = true）

以下出现在 contact.name 中时，即使没有价格、URL 或其他字段也可直接判定：

* 招募赚钱、兼职获利、日赚/月赚、收益承诺
* 收款、代收、跑分、洗钱、资金周转等交易语义
* 博彩、充值、代理、返利、投资等获利活动
* 商品/服务出售、购买、代办、接单等明确商业行为
* 成人服务、色情资源交易或付费服务
* 明确要求通过微信、支付宝、QQ、Telegram 等方式联系以参与上述活动

---

## 特别规则：获利语义 + 联系方式 = 明确广告引流

“赚钱/兼职/收益/项目/代收”等获利语义与“微信/支付宝/QQ/联系”等联系方式出现在**同一个联系人名称**中时，视为明确广告引流，不要求额外出现价格、URL 或完整交易闭环。

| Contact name | 判定 |
| --- | --- |
| 小明 / 技术交流群 / 游戏交流群 | contact_ad=false |
| 有微信支付宝来赚钱 | contact_ad=true，confidence >= 0.95 |
| 兼职日赚500 | contact_ad=true，confidence >= 0.95 |
| 代收款 一单100 | contact_ad=true，confidence >= 0.97 |
| 博彩充值代理 | contact_ad=true，confidence >= 0.99 |
| 美女陪聊 | 视上下文，单独通常不足 |
| 免费领取游戏礼包 / 优惠活动 | 通常不直接判广告 / 单独不足以判定 |

---

## 不能单独判定广告的弱线索

普通姓名、普通昵称、普通群组/频道名称、单独出现微信/支付宝/QQ/Telegram（无获利/交易语义）、单独出现“赚钱”“兼职”“项目”等模糊词（无联系方式/支付方式）、普通兴趣/游戏/软件/社区名称。

---

## 字段隔离

contact_ad 只反映 contact 字段，不得把 profile.name / profile.bio / message 的内容复制到 contact 判断中。
