# Message 规则

message 是当前发送者自己写的内容，是最重要的证据来源。重点识别：

## 关键词类别

* **交易**：出售 / 售卖 / 购买 / 求购 / 代购 / 代收 / 收款 / 充值 / 交易 / 价格 / 报价 / 代理 / 加盟
* **获利**：日赚 / 月赚 / 赚钱 / 收益 / 返利 / 佣金 / 项目 / 兼职 / 招代理 / 高收益 / 稳赚
* **商业推广**：官方代理 / 招商 / 推广 / 合作 / 优惠 / 折扣 / 促销 / 购买 / 付费 / 服务
* **非法交易**：洗钱 / 代收代付 / 黑产 / 资金盘 / 博彩 / 赌博 / 下注 / 充值 / 非法交易

但单个词不能机械判定。例如：“有人讨论洗钱案件” 不是广告；“来洗钱，挣8千” 属于明显非法获利引导。

# 公共平台分享：默认不是广告

公共内容平台：Google / Google Play / App Store / YouTube / X / Twitter / TikTok / 抖音 / 快手 / Bilibili / Instagram / Facebook / Reddit / GitHub / Steam / Microsoft Store。

如果用户只是分享软件、应用、视频、网页、GitHub 项目、游戏、文章或普通资源，推荐自己正在使用的软件：**不得判定为广告**。例如 “Check out Novagram Messenger https://play.google.com/store/apps/details?id=xxx” 必须 ad_detected = false（普通应用分享）。

**不能因为 URL 指向 Google Play、YouTube、X、TikTok、Bilibili 等平台就判定广告。** 只有出现商业语义时才可能成为广告，例如：“这个软件官方代理，购买联系我”“现在购买这个软件有优惠”“加入推广计划，每邀请一个人获得佣金”“注册后返利”。

# Telegram 链接不是广告

以下内容单独出现时不是广告：t.me/xxx、t.me/xxx?direct、t.me/+xxxx、@username、私信/DM、联系我/联系管理员、我的频道/我的群/我的机器人、频道/群组、Telegram 联系方式。

例如 “这是我的频道 @abc”“有问题私信我”“t.me/abc?direct” 都必须 ad_detected = false，除非上下文存在明确的商品、服务、交易、收益、成人服务、博彩、非法交易或商业推广。

# 组合证据升级（不是完整闭环）

不要把每个字段孤立判断，也**不要**要求“商品+价格+联系方式+URL”全部出现。线索组合一旦足以表达推广/招募/交易/获利/引流意图，直接升级判定。

| 组合 | 例子 | 判定 |
| --- | --- | --- |
| A：交易 + 联系方式 | “出售XX @abc” | 广告 |
| B：收益 + 联系方式 | “日赚500，联系我” | 广告 |
| B2：获利 + 支付方式 | “有微信支付宝来赚钱” / “做代收 一天1W” | 强广告，不需 URL |
| C：项目 + 收益 + 群组 | “赚钱项目，日赚8千，加群” | 高置信广告 |
| D：非法交易 + 收益 | “来洗钱，挣8千” | 高置信非法交易广告 |
| E：成人内容 + @用户名 | “激情爆操 @abc” | 成人引流广告 |
| F：成人内容 + 私信 | “成人服务，私信” | 成人引流广告 |
| G：成人内容 + Telegram 链接 | “成人服务 t.me/xxx” | 成人引流广告 |
| H：普通软件 + Google Play | “推荐一个很好用的软件 + GP 链接” | **不是**广告 |
| I：YouTube/X/TikTok/Bilibili 分享 | 有 URL/@用户/视频/频道但无商业获利语义 | **不是**广告 |
| J：主页引流 + 成人/资源频道 | “宝宝主页有好看的 / 主页自取 / 去主页看” + PersonalChannel 含「私密资源/福利/吃瓜/限时/🈲🔞」 | 成人/付费资源引流广告，Channel_ad=true，confidence>=0.90 |

组合 J 不要因为 message 本身“看起来模糊”就放行；要看它把用户导向了哪个频道。

# 成人引流（message 上下文）

如果成人语义同时存在 @用户名、私信、DM、t.me、频道、群组、联系方式、机器人、购买入口、付费、价格、服务或资源下载入口，则判断是否存在成人引流。

如果联系方式承担“联系成人服务/获取成人资源”的作用：ad_detected = true，r18 = true。例如均属成人引流：“成人服务 @abc”“约炮 @abc”“陪玩私信”“色情资源加群”“成人视频联系我”。

如果只是成人话题讨论（无引流）：r18 = true，ad_detected = false。
